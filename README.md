# TechNest

An Electronics Shop Inventory Management System built with Spring Boot.

TechNest is a backend development project focused on building a practical inventory management system for an electronics shop. It is also my hands-on journey into understanding Spring Boot and real-world Java backend development.

## About the Project

The goal of TechNest is to build a structured backend that handles product management, database operations, business logic, and inventory-related functionality while following clean coding practices.

Rather than relying on shortcuts, the project focuses on understanding how Spring Boot works internally and how its concepts are applied in real applications.

## Tech Stack

- Language: Java 21
- Framework: Spring Boot
- Build Tool: Maven
- Database: H2
- Database Access: JDBC / JdbcTemplate
- Architecture: Controller – Service – Repository
